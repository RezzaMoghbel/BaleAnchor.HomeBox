- `PRODUCTION_CONFIGURATION_MATRIX.md` — production key matrix with validation rules and commit/secrets boundaries.
- `ENVIRONMENT_AND_SECRETS.md` — runtime environment variable and secret injection policy.
- `DEPLOYMENT_RUNBOOK.md` — release deployment and rollback procedure.
- `BACKUP_RESTORE_RUNBOOK.md` — JSON persistence backup/restore and dry-run procedures.
